# Aria: Sovereign Edge AI

## intro
Modern language models usually run in centralized server farms. [#cloud]
Every user prompt leaves the local device, exposing private data and creating recurring subscription costs. [#edge]
Aria introduces a sovereign edge architecture that runs completely on personal hardware.

## hardware
Aria is optimized for consumer laptops and compact edge servers. [#specs]
It targets an {NVIDIA|N-vidia} {GTX 1650|G-T-X sixteen fifty} mobile {GPU|G-P-U} with four gigabytes of {VRAM|V-ram}. [#split]

## duel
Standard small models fail when tasks require strict tools or deep logic. [#raw]
The raw base model hallucinates missing packages and crashes on syntax errors. [#aria]
Aria generates a structured thought block to verify algorithm invariants before executing.

## sandbox
Local code execution demands strict blast radius controls. [#firewall]
Aria routes every operation through an abstract syntax tree firewall across four isolated tiers. [#tiers]
Harmful terminal calls and dangerous socket manipulations are blocked before any process starts.

## reflexion
When an unexpected exception occurs, Aria repairs itself autonomously. [#distill]
The traceback distiller isolates the exact failing line and extracts the error message. [#loop]
Aria feeds this signal back into its reasoning scratchpad to produce a working fix.

## rlvr
In phase ten, Aria evolved using Group Relative Policy Optimization. [#grpo]
The system generates four rollout candidates and scores them against deterministic test rewards. [#advantage]
Reinforcement learning updates policy weights directly on the four gigabyte {GPU|G-P-U}.
